# 设计与数据约定

四个模块共享几何和本体，调用关系为：图片工具 → 训练 → 原图预测／评价 → 分析。训练框架只在训练和 YOLO 预测时导入，因此 Mac 可以只装轻量依赖。原图评价是独立命令，不嵌入每个 epoch 的训练回调。

## 输入

使用项目已有的原始 401 类 YOLO 格式，类别顺序必须与 `configs/ontology.csv` 的 `source_id/source_name` 完全一致：

```text
/data/mtsd/
  classes.json                 {"names": [401 个原始名称，按原始 ID 排列]}
  train_full/images/*.jpg
  train_full/labels/*.txt
  val/images/*.jpg
  val/labels/*.txt
```

每行标签为 `class_id cx cy width height`，坐标相对该原图归一化。图片与标签一一对应；已确认没有目标时使用空 `.txt`，缺失标签报错。未完整标注的 `train_partial` 不参与本轮。官方原始 MTSD JSON 标注需要先转换为这一格式，本仓库不假定 JSON 和 YOLO 的数字 ID 天然相同。

`configs/data.yaml` 的路径相对配置文件目录解析。默认示例使用 `/data`；实际目录由用户在 Ubuntu 上设置。输入目录保持只读，输出必须使用新目录。构建失败会保留操作日志和已生成文件；没有完成生成的 `data.yaml` 就不能开始训练，重新构建使用新的输出目录。

## 图片准备

- 1280×1280 切片，水平和垂直重叠 20%。不足 1280 的边长只补边，不把小图片放大后当成原尺寸切片。
- 切片框剩余面积至少 100 像素，且至少保留原框面积的 20%。保留所有切片，包括空标签的负样本。
- 同时生成训练用的 1280 整图视图。但只要某个保留目标缩放后的短边低于 16 像素，就省略整张整图视图，保留其切片。这样不会把缩小后删掉的目标当成背景。
- 含有 `review` 标签的原图整体留待复核，不把歧义框删掉后继续当作负样本。`exclude` 是本轮检测范围之外的类别，其框不进入目标标签。
- 原图 GT 从原始标签直接映射，不用切片 GT 拼凑，不应用切片的面积过滤。
- 保持原 train/val 划分。移除 `fully_train_` 等来源前缀后检查原图 ID，并检查跨集合的相同图片内容，避免切片泄漏。

输出包括 `images/{train,val}`、`labels/{train,val}`、`data.yaml`、`val.coco.json`、`ontology.json`、`manifest.json`、配方、环境和逐图操作日志。Manifest 记录原图 ID、尺寸、标签和图片校验和、每张切片的坐标、过滤情况、各类别原图实例数。

原图评价仍读取原始 JPG。`val.coco.json` 中保留原图绝对路径和校验和，所以训练用切片不能替代原图。跨设备搬运数据时应保留同样的挂载路径，或在目标设备从原图重新构建。

## 抽样与增强

训练采用有放回抽样，长期概率为 70% 切片、30% 合适的整图。每个 epoch 的抽样次数为准备后训练图片数；一个小 batch 不保证刚好 70/30，也不保证一个 epoch 遍历每张图片。主样本和 Mosaic 的另外三个样本使用同样的抽样规则，随机种子由训练框架管理。

若没有任何合适的整图，先看数据报告，明确选择切片基线时将 `training.full_ratio` 设为 0 并重新生成数据；代码不会静默改变抽样比例。

Mosaic 在 1280 画布内按随机中心拼接四张图，不把四张图统一缩小到 640。每张图按 0.9–1.1 缩放；存在短边小于 32 像素的框时，下限为 1.0。缩放采用实际取整后的尺寸，再处理画布与各象限的可见区域。剩余面积相对缩放后的完整框至少 60%，短边至少 16 像素。

不叠加第二次随机透视或缩放，不水平／垂直翻转，不旋转，不做 MixUp。最后 10 个 epoch 关闭 Mosaic。最终自然样本阶段仍使用同一 70/30 抽样分布。

## 版本与日志

本体快照、数据指纹、实际代码指纹、Git 状态、依赖版本、初始权重校验和和 GPU 信息进入运行记录。类别变动会改变本体指纹，禁止将旧权重的类别名直接套入新 GT。

预测逐图片提交结果，空预测同样有完成文件。只有模型、GT 和推理配置都相同才允许恢复；全部图片完成后才能进入评价。训练结果保存为 `run/model/`，项目自身记录在 `run/`，避免框架多 GPU 启动时清理内部输出目录而删除记录。

训练出现非有限 loss 时停止，并保存该批次的来源路径、增强后图片张量与标签。证据用于排查，不将原因预先归结为 AMP 或显卡。

## 依据

MTSD 是全球采集的数据，不是天然的欧洲数据集，参见 [数据集论文](https://arxiv.org/abs/1909.04422)。训练适配固定使用 [Ultralytics 8.3.225 数据集接口](https://github.com/ultralytics/ultralytics/blob/v8.3.225/ultralytics/data/dataset.py)；升级需重跑适配器测试，不能只更新版本号。
